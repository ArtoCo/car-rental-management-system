# Car Rental System

A Java NetBeans car rental management system using Java Swing and MySQL.

## Technologies Used
- Java
- Java Swing
- NetBeans IDE
- MySQL

## How to Open
1. Open NetBeans.
2. Click File > Open Project.
3. Select this project folder.
4. Configure the MySQL database connection if needed.
5. Run the project.

## Important Note
Do not upload private database passwords or sensitive configuration files to GitHub.
